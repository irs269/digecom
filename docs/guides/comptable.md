# Comptable

Vous vérifiez les relevés des e-commerçants et vous saisissez les dépenses.

![Tableau de bord](img/comptable-tableau-de-bord.png)

## Tâches courantes
- **Relevés à vérifier** (tous les 14 jours, générés automatiquement) : contrôler chaque ligne (commissions, taxes, abonnements, report du cycle précédent), puis « Vérifier ».

  ![Règlements](img/comptable-reglements.png)
- **Dépenses** : saisie avec justificatif ; elles sont ensuite validées par le responsable financier.
- **Solde bancaire** : saisie périodique.
- **Rapports** : marges, règlements, dépenses.

  ![Rapports](img/comptable-rapports.png)

## À savoir
- Un relevé faux ne se corrige pas à la main : on corrige la commande (retour, refus), et les écritures inverses passent au cycle suivant. Voir [EXPLOITATION.md](../EXPLOITATION.md).
- Le grand livre est **append-only** : aucune écriture n'est jamais modifiée ni supprimée.
