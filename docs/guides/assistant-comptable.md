# Assistant comptable

Vous tenez la caisse avec le caissier et vous saisissez les dépenses.

![Tableau de bord](img/assistant-comptable-tableau-de-bord.png)

## Tâches courantes
- **Caisse** : ouverture, encaissements (dont l'argent remis par les livreurs), décaissements, clôture avec l'écart entre le théorique et le réel.

  ![Caisse](img/assistant-comptable-caisse.png)
- **Dépenses** : saisie avec justificatif.

  ![Dépenses](img/assistant-comptable-depenses.png)
- **Règlements** : consultation seule.
